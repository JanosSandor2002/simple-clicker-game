# Simple Clicker Game

A text/console-based Java game built with **native Java** (no external frameworks), created as a way to get hands-on experience with the language.

## About

In Simple Clicker Game, you start by choosing a class, then face off against **13 enemies** you'll need to defeat. Each class comes with its own special moves and unique stats, so the way you play can vary significantly depending on your choice.

## Features

- Class selection system
- 13 unique enemies to defeat
- Class-specific special moves
- Unique stats per class

## Tech Stack

- **Java** (native, no external frameworks)

## Running the Jar

Make sure you have a JDK installed, then run:

```bash
java -jar simple-clicker-game.jar
```

## Goals of This Project

This project was built primarily as a **learning exercise** in native Java — practicing OOP design (classes, inheritance for enemy/character types), game loop logic, and console-based interaction without relying on external libraries or frameworks.
