# Simple Clicker Game

Egy szöveges/konzolos Java játék, amely **natív Java**-val készült (külső keretrendszerek nélkül), azzal a céllal, hogy gyakorlati tapasztalatot szerezzek a nyelvvel.

## A játékról

A Simple Clicker Game-ben egy karakterosztály kiválasztásával kezdesz, majd **13 ellenféllel** kell szembenézned, akiket le kell győznöd. Minden osztálynak megvannak a saját speciális képességei és egyedi statisztikái, így a választástól függően a játékmenet jelentősen eltérhet.

## Funkciók

- Osztályválasztó rendszer
- 13 egyedi legyőzendő ellenfél
- Osztályspecifikus speciális képességek
- Egyedi statisztikák osztályonként

## Technológiai stack

- **Java** (natív, külső keretrendszerek nélkül)

## Kipróbálás

Egy letölthető `.jar` fájl érhető el, amely JDK-val futtatható:

👉 [Letöltés Google Drive-ról](https://drive.google.com/drive/folders/1lNvvRAqOzIF4pnWUgEcFEpYMFFZNNJrm?usp=drive_link)

### A jar futtatása

Győződj meg róla, hogy telepítve van egy JDK, majd futtasd:

```bash
java -jar simple-clicker-game.jar
```

## A projekt célja

Ez a projekt elsősorban **tanulási gyakorlatként** készült natív Java-ban — OOP tervezés gyakorlása (osztályok, öröklődés az ellenfél/karakter típusokhoz), játékciklus logika, és konzolos interakció megvalósítása külső könyvtárak vagy keretrendszerek nélkül.
